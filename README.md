## About
I'm studying BSc Cybersecurity & Networking Engineering, currently completing my Studienkolleg foundation year. This repo tracks my hands-on learning: small projects, scripts, and notes as I build skills from the ground up.

## Projects

### Port Scanner
`python_projects/port_scanner.py`

A basic Python script that scans the first 100 ports on a target IP and reports which ones are open. Built to understand how port scanning works at a fundamental level before using professional tools like Nmap.

**Usage:**

python port_scanner.py

Enter a target IP when prompted. Only scan systems you own or have explicit permission to test.
